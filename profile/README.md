# EnvFoundry

**Open environments for autonomous research.**

Build an experiment. Run a calculation. Prepare data. Learn from the result.

EnvFoundry develops the environments in which researchers and agents do this work. Each project is independently usable and versioned, with documented interfaces for existing research systems.

| Environment | Work with |
| --- | --- |
| [IOP](https://github.com/EnvFoundry/IOP) | Physical instruments, experimental platforms, persistent operations and measured data. |
| [Optics–Photonics AI Lab](https://github.com/EnvFoundry/Optics-Photonics-AI-Lab) | Optical modelling, scientific solvers, parameter studies and result analysis. |
| [Data Engineering](https://github.com/EnvFoundry/Data-Engineering) | Versioned data releases, budgeted mixtures and resumable data consumption. |
| [Verifiable Agent Gym](https://github.com/EnvFoundry/Verifiable-Agent-Gym) | Executable tasks, independent evaluation and reusable trajectories for learning. |
| [AI Evaluation](https://github.com/EnvFoundry/AI-Evaluation) | Benchmark design, reproducible comparisons, judge calibration and evaluation research. |

[Explore the environments](https://github.com/EnvFoundry/environments) · [Machine-readable catalogue](https://github.com/EnvFoundry/environments/blob/main/catalog.json) · [Contribute](https://github.com/EnvFoundry/environments/blob/main/CONTRIBUTING.md)

Use Python, the command line, MCP, or an environment's documented service API. Agentic Research OS, coding agents, other research systems and human researchers can use the same environments. The directory records the interfaces and prerequisites available in each project.

Contributions belong in the environment they improve. New domains are welcome: bring a working example, clear inputs and outputs, and instructions for running it.

**面向自主研究的开放环境。**

EnvFoundry 持续开发和维护仪器实验、科学计算、数据工程、任务学习与 AI 评测环境。各环境独立安装、独立发布，通过明确的接口供研究人员、Agent 和不同研究系统使用。
