# Contributing to EnvFoundry

Use the [environment directory](https://github.com/EnvFoundry/environments) to find the project that owns your change. Each environment maintains its own implementation, dependencies and releases.

Open a topic branch and a pull request against the corresponding **EnvFoundry** repository. Read that project's contribution instructions and run the checks relevant to the change. Explain the behavior that changes and include a working example when adding an interface or capability. Preserve existing consumers, contributor attribution and licenses.

For a new environment, start with a working research task, clear inputs and outputs, and reproducible installation instructions. Add its entry to the [catalogue](https://github.com/EnvFoundry/environments/blob/main/CONTRIBUTING.md) once the repository and example are usable.

Report bugs in the affected environment's Issues. Use the directory's Issues for catalogue errors or proposals that span environments.

## 中文

请向对应的 **EnvFoundry** 仓库提交议题和拉取请求。各研究环境独立维护和发布；修改前阅读该项目的说明，提交能运行的示例与相关检查结果。新增研究环境从实际任务、明确的输入输出和可复现安装方式开始，再加入统一目录。
